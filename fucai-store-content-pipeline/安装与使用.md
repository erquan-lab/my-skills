# 福彩门店内容流水线 · 安装与使用

> 一句话：装好后在对话里发「主题：门店便民」，就能拿到一套可直接拍的内容。

## 一行命令安装

**Windows**（PowerShell 里粘贴，回车）：

```powershell
powershell -c "irm https://raw.githubusercontent.com/erquan-lab/my-skills/main/install-fucai.ps1 | iex"
```

**macOS / Linux**：

```bash
curl -fsSL https://raw.githubusercontent.com/erquan-lab/my-skills/main/install-fucai.sh | bash
```

看到 `[完成] 已安装到 ……` 就装好了，**重启豆包后生效**。

## 脚本干了什么

1. 把内嵌的技能包解到系统临时目录；
2. 在 `%LOCALAPPDATA%\Doubao`、`%APPDATA%\Doubao` 下找豆包的 `.user_skills` 目录；
3. 把 `fucai-store-content-pipeline` 复制进去。已有同名技能会先改名备份（`.bak_时间戳`），不删除任何东西。

找不到目录时脚本会打印手动路径，不会强行写盘。

## 手动安装

把 `fucai-store-content-pipeline` 整个文件夹放进：

```
%LOCALAPPDATA%\Doubao\User Data\Default\.doubao\agent_mode\workspace\.user_skills\
```

目录名必须保持英文，不能改成中文。

## 怎么用

```
主题：门店便民
```

可选补充：`门店：xxx`、`平台：抖音`、`时长：15 秒`。只有「主题」必填。

## 输出六段

A 选题合规预判 → B 15 秒口播（70–95 字，8 行字幕）→ C 即梦配图提示词 → D 剪映成片清单 → E 发布包（标题 3 选 1、封面 8 字、同城话题）→ F 合规自查。

## 合规红线

不荐号、不晒票、不承诺、不网售、不涉未成年人；每条结尾统一「理性购彩，量力而行」。
完整清单见 `references/compliance-guardrails.md`。
