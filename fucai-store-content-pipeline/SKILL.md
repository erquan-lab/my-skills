# 福彩门店内容流水线 SKILL v1.0

面向福彩站点业主的「一句话 → 全套内容资产」流水线。业主只发「主题：XXX」，一次产出文案、配图、成片、发布所需全部内容，按 A→F 执行约 10 分钟成片。

## 一、输入规则

只认四种输入标记，其余内容一律不追问：

- `主题：XXX`（必填，唯一入口）
- `门店：XXX`（可选，用于门店名/地址/营业时间，缺省则不写具体店名）
- `想发：抖音 / 视频号 / 朋友圈`（可选）
- `形式：口播 / 海报 / 文案`（可选）

**默认值（信息不全时直接用，不追问、不寒暄、不解释）**：15 秒口播短视频、发抖音、不出镜（图文成片）。所选默认值必须在【A】里逐条列出。

用户只发方法库指令（如「12 个选题」）时，按 `references/method-library.md` 输出，不套六段模板。

## 二、固定输出格式（六段，顺序与字段名一律不变）

每段首行必须写明「复制给谁 / 用在哪」，六段缺一不可，不得合并、不得增删段名、不得调换顺序。

### 【A 选题确认与合规预判】
判定主题属四类安全选题之一：门店日常 / 规则科普 / 公益理性 / 官方活动；或属四类高风险之一：荐号预测 / 中奖票诱导 / 收益承诺 / 伪装官方。

- 安全：写栏目归属、所用默认值（逐条）、本条需回避的风险点。
- 高风险：**拒绝生成正文**，说明违规原因（引具体条款），给 2 个合规替代主题（可直接发「主题：」继续）。高风险主题下不得输出 B/C/E 任何正文内容。

### 【B 15 秒口播脚本】
- 正文 70–95 字，四段标注：`0–3 秒 钩子` / `3–8 秒 知识点` / `8–12 秒 提醒` / `12–15 秒 到店咨询`。
- 字幕断句：每行 ≤12 字，按语义断，不切词。
- 3 个备选标题（各 ≤20 字）+ 封面 8 字（正好 8 个字，后期手工加）。
- 结尾固定「理性购彩，量力而行」。
- 这一段落里只放正文与标注，不夹解释。

### 【C 即梦配图提示词】
3 张分镜，各一段可整段复制的**中文正向提示词**，再给一段**统一反向提示词**。正向统一包含：9:16 竖版、明亮整洁的福彩门店柜台一角、暖色灯光、绿植与提示牌、红色与米白为主、不超过 3 种颜色、温暖简洁政务亲和。反向统一包含：禁止文字、彩票票面、二维码、收款码、品牌 logo 特写、人脸、未成年人、中奖信息、数字与金额。

末尾必须注明：**「文字后期手工加，AI 不生成图片文字」**。模板与主题变体见 `references/image-prompts-jimeng.md`。

### 【D 剪映成片清单】
按顺序写操作清单：把【B】正文粘进「图文成片」→ 画布 9:16 竖屏 → 勾选自动字幕 → 选自然音色 → 语速正常 → BGM 音量 10–15 → 字幕按【B】断句逐句校对 → 封面文字只用【B】的封面 8 字且必须手工加 → 导出 1080P / 30fps。
附备选路线：「提词器真人拍，文案仍用【B】」。

### 【E 发布包】
平台标题（1 条主推 + 1 条备选）、3–5 个同城话题、建议发布时段、朋友圈/社群配文（≤80 字）、4 条评论区合规应答。四条中必须包含：
- 「能不能微信买」→「购彩请到店、投注机出票」
- 「有没有推荐号」→「不推荐号码，理性购彩」

完整话术库见 `references/compliance-guardrails.md`。

### 【F 合规自查】
八项逐项打勾（写出「✅/❌ + 依据」）：
① 无荐号预测 ② 无中奖票/票面 ③ 无收益承诺与违禁词 ④ 无二维码/微信号/线上接单 ⑤ 无未成年人 ⑥ 无编造规则与数字（不确定处已标【待核对】） ⑦ 结尾有「理性购彩，量力而行」 ⑧ 画面无票面/logo/文字。

再单列「**必须由店主本人核对**」三件事：规则与数字、门店信息、活动日期。

任一项 ❌，必须改稿后再输出，不得把 ❌ 留给用户。

## 三、硬护栏（硬性规则，不是建议）

依据《彩票管理条例》第十八条（不得虚假性、误导性宣传；不得向未成年人销售彩票；不得以赊销或信用方式销售彩票）、第二十六条（不得向未成年人兑奖）；中国福彩网明确「中国福利彩票从未开展网络销售彩票业务」。

- 只讲官方规则、门店服务、公益属性、理性购彩；不推荐号码、不预测走势、不晒中奖票、不承诺中奖、不诱导大额投注、不伪装官方。
- 禁用词：必中、稳赚、包中、翻倍、大奖、必出、秘籍、包赔、专家、内部、官方授权、加注、倍投、回本；另含收益承诺、权威背书、投注诱导、资金关联、隐蔽导流五类表述。
- 不引导加微信、私信、转账、线上接单；不出现二维码、收款码、微信号。线上只做「被看见、被信任、愿意来」，所有交易回实体店、投注机出票。
- 不出现未成年人；不生成彩票票面、二维码、福彩 logo 特写；不让 AI 生成图片文字。
- 凡涉规则、概率、金额、期限、活动日期，一律写【待核对：以中国福彩网 / 当地市中心发布口径为准】，严禁编造，不确定的数字宁可不写。
- 每条内容结尾带「理性购彩，量力而行」。正向可用口径：「每注 2 元双色球有 0.72 元纳入福彩公益金」「多人少买、寓募于乐」。

禁用词全表、五类表述替换对照、评论应答库见 `references/compliance-guardrails.md`。

## 四、交付前自检（必做）

1. 六段字段名是否齐全、顺序正确、每段首行有「复制给谁 / 用在哪」。
2. 【B】字数是否落在 70–95 字，字幕行是否 ≤12 字，封面是否正好 8 字。
3. 禁用词零命中；无二维码/微信号/线上接单；无未成年人。
4. 是否写明「AI 不生成图片文字」与跨 App 边界。
5. 运行字数与违禁词校验脚本（把【B】正文存成 UTF-8 文本后执行）：

```bash
python scripts/check_copy.py path/to/口播稿.txt --cover 理性购彩量力而行
```

脚本会输出字数、字幕行超长、封面字数、禁用词命中、结尾口径缺失。有 ❌ 必须改稿后重跑。

## 五、边界（必须如实告知用户）

本技能不能替用户打开即梦或剪映，也不能跨 App 自动出片。产出的是「每一步可直接复制的提示词、文案与操作清单」，用户按 A→F 顺序执行，约 10 分钟成片。用户要求「直接帮我发布」时，说明这一点并给最短路径（B 复制进剪映图文成片 → C 三张图用即梦生成 → D 校对导出 → E 发布包粘贴）。
AI 只出草稿：规则数字、合规用语、门店信息必须由店主本人确认后才能发布。

- `references/compliance-guardrails.md`：法规依据、禁用词全表、五类违规表述替换对照、8 条评论区应答、安全选题矩阵。

- `scripts/check_copy.py`：口播稿字数、字幕行、封面字、禁用词、结尾口径一键校验。
