# 即梦配图提示词模板（【C】段）

固定 3 张分镜。每段正向提示词都要能整段直接粘贴，不加评论、不写括号说明。文字一律后期手工加。

## 统一正向骨架

```
9:16 竖版画面，明亮整洁的福彩门店柜台一角，暖色灯光，柜台上摆放整齐的宣传单页与绿植，旁边立一块空白提示牌；红色与米白为主色调，画面不超过 3 种颜色；温暖、简洁、政务亲和；真实室内光照，柔和阴影，高清细节。
```

三种分镜差异（只替换后半句焦点，前半段骨架不动）：

- 分镜 1 · 场景建立：`中景，柜台正前方视角，桌面干净，背景是整齐的墙面与宣传架，留出上方空白区域。`
- 分镜 2 · 服务动作：`近景，一个着装整洁的工作人员双手整理单页的动作，只见手臂与桌面，不见脸，桌面留出空白区域。`
- 分镜 3 · 提示与氛围：`中近景，柜台上立着一块完全空白的红色提示牌，旁边一盆小绿植，背后暖光晕开，画面留白充足。`

## 统一反向提示词

```
画面中不得出现任何文字、数字、金额、二维码、收款码、条形码、彩票票面、刮刮卡实物、中奖信息、品牌 logo 特写、人脸、人物正脸、未成年人、制服徽标、钞票、手机屏幕界面；不要卡通风、不要赛博朋克、不要夸张滤镜、不要暗调、不要脏乱背景、不要过度饱和。
```

## 主题化替换（按选题微调焦点，骨架与反向词不变）

| 主题类型 | 分镜焦点替换 |
|---|---|
| 门店日常 | 营业时间/新票到店：柜台整齐陈列的单页与空白立牌；店内一角干净明亮 |
| 规则科普 | 桌面上摊开的空白手册与一支笔，强调「可讲解」的场景感 |
| 公益理性 | 绿植+暖光+空白提示牌，画面更安静，留白更多 |
| 官方活动 | 柜台主位一块空白红色立牌，背景宣传架整齐，突出「公告」感 |
| 兑奖提醒 | 柜台抽屉半开、整齐的票据收纳盒（不出现任何票面图案） |
| 便民服务 | 门口视角的柜台与座椅，暖光，干净地面 |

## 输出格式（照抄这个结构）

```
【C 即梦配图提示词】复制给即梦（图片生成），每张单独一次生成，1:1 用不到，选 9:16。

分镜 1（场景建立）：
<正向提示词整段>

分镜 2（服务动作）：
<正向提示词整段>

分镜 3（提示与氛围）：
<正向提示词整段>

统一反向提示词（三个分镜都填）：
<反向提示词整段>

注：文字后期手工加，AI 不生成图片文字。出图后如出现文字、二维码、票面、人脸，直接重生成或用「换个分镜」重出。
```

## 出图验收（3 秒判断）

1. 没有任何文字与数字（包括道具上的小字）。
2. 没有票面图案、二维码、收款码、logo。
3. 没有人脸、没有像未成年人的形象。
4. 画面≤3 种颜色，主色是红与米白，整体亮。
任一条不过，重生成，不将就。
