# 合规护栏（硬性规则）

本文件是【A】【F】两段的判定依据，也是所有输出的一票否决清单。任何一条不满足，改稿后再输出。

## 一、法规与官方口径依据

| 依据 | 条文要点 | 对内容的约束 |
|---|---|---|
| 《彩票管理条例》第十八条（国务院令第554号） | 彩票发行机构、销售机构、代销者不得：(一) 进行虚假性、误导性宣传；(二) 以诋毁同业者等手段进行不正当竞争；(三) 向未成年人销售彩票；(四) 以赊销或者信用方式销售彩票 | 不夸大奖项、不暗示必中；不贬低同业；画面与话术不出现未成年人；不出现「先拿票后付钱」「记账」「垫资」类表述 |
| 《彩票管理条例》第二十六条 | 按品种规则和兑奖操作规程兑奖；奖金以现金或现金支票一次性兑付；**不得向未成年人兑奖** | 兑奖类内容只讲「带票到店/按规则兑」，不讲代办、代兑、垫付 |
| 《彩票管理条例》第四十一条 | 代销者虚假误导宣传、向未成年人售彩、赊销信用销售，责令改正并处 2000 元以上 1 万元以下罚款，可解除代销合同 | 违规不是「流量风险」，是可直接处罚与解约的合规风险 |
| 《彩票管理条例实施细则》第二十九条 | 难以判断购买者/兑奖者是否未成年时，可要求出示有效身份证件 | 门店类内容可正向讲「看着小我们会请出示证件」，这是合规动作而非刁难 |
| 《未成年人保护法》第五十九条 | 禁止向未成年人销售烟酒彩票或兑付彩票奖金；经营者应在显著位置设置不向未成年人销售彩票的标志 | 门店日常内容可拍「不向未成年人售彩」提示牌（提示牌文字后期手工加） |
| 中国福彩网公开表述 | 中国福利彩票从未开展网络销售彩票业务 | 一切「线上购买」「微信转账出票」「代购代刮」都是违规，直接拒绝 |

> 条文以国家法律法规数据库/中国福彩网现行发布为准；如当地市中心另有细化口径，以市中心为准。凡引用条款号，不得臆造。

## 二、赛道判定矩阵（【A】段用）

四类安全选题：
1. **门店日常**：营业时间、新票到店、店内环境、服务动作、兑奖提醒、便民服务。
2. **规则科普**：玩法规则、开奖流程、兑奖期限与所需证件、如何辨别正规网点。
3. **公益理性**：公益金去向、资助项目、理性购彩倡导、多人少买、寓募于乐。
4. **官方活动**：中国福彩/省福彩中心/当地市中心已正式发布的活动，原样转述，数字不改。

四类高风险（出现即拒绝生成正文）：
1. **荐号预测**：「这期看好哪几个号」「杀号」「走势必出」「跟着我买」。
2. **中奖票诱导**：晒票面、晒中奖截图、晒兑奖单、「昨天店里中了多少」。
3. **收益承诺**：稳赚、回本、翻倍、包中、投入多少能中多少。
4. **伪装官方**：以官方口吻发布未公开信息、自称官方授权/合作、冒充市中心通知。

拒绝时的固定结构：① 判定 → ② 违反哪条（引条款或官方表述）→ ③ 2 个可直接替换的合规主题（写成「主题：XXX」）。

## 三、禁用词与五类违规表述（零容忍）

**直接禁用词（命中即改）**：必中、稳赚、包中、翻倍、大奖、必出、秘籍、包赔、专家、内部、官方授权、加注、倍投、回本。

| 违规类型 | 典型说法 | 改成 |
|---|---|---|
| 收益承诺类 | 稳赚不亏 / 投入 100 回本 / 中奖率高 / 买了就翻倍 | 中奖是随机事件，每注机会相同 |
| 权威背书类 | 专家推荐 / 内部消息 / 官方授权店 / 站长亲手选号 | 本站是福彩正规代销网点，按官方规则销售 |
| 投注诱导类 | 多买多中 / 加倍投注 / 追加投入 / 趁活动多囤 | 多人少买、寓募于乐，按自己节奏来 |
| 资金关联类 | 转账出票 / 先票后款 / 记账赊销 / 垫资代购 | 购彩请到店，投注机出票，现金或合规支付 |
| 隐蔽导流类 | 加微信私聊 / 扫码进群 / 私信我发号码 / 后台下单 | 门店地址在主页，欢迎到店咨询 |

**替换优先级**：能删就删 > 换成中性事实 > 换成合规正向口径。绝不为了「更有吸引力」保留半个违规表达。

## 四、评论区 8 条应答（【E】段选 4 条）

1. **能不能微信买** → 「购彩请到店、投注机出票，线上不接单，也从不网售。店在××，营业时间××。」
2. **有没有推荐号** → 「不推荐号码，理性购彩。每注机会一样，选自己喜欢的号就好。」
3. **昨天是不是中了大奖** → 「中奖信息以中国福彩网公布为准，店里不晒票、不传中奖细节。」
4. **能帮我代刮/代兑吗** → 「刮票和兑奖都要本人到店，带票来就行，我们按官方规则办。」
5. **活动是真的吗** → 「活动以中国福彩网和当地市中心发布为准，我把官方原文放主页，具体日期【待核对】。」
6. **小孩能买吗** → 「不向未成年人销售彩票、也不向未成年人兑奖，看着小我们会请出示证件。」
7. **有内幕吗/跟着你买行不行** → 「没有内幕，也不做推荐。彩票是随机游戏，量力而行就好。」
8. **能赊账先拿票吗** → 「按规定不能赊销、不能信用方式销售，到店现金或合规支付。」

## 五、正向口径库（可直接用）

- 「每注 2 元双色球，其中约 0.72 元纳入福彩公益金」（比例随政策调整，引用前【待核对】以中国福彩网公布为准）
- 「多人少买、寓募于乐」
- 「中国福利彩票从未开展网络销售彩票业务」
- 「理性购彩，量力而行」
- 「买彩是随手公益，不是理财」
- 「中奖是随机事件，每一注机会相同」
- 「不向未成年人销售彩票、不向未成年人兑奖」
- 「购彩请到店，投注机出票」

## 六、必须标注【待核对】的情形

规则条款、玩法细节、概率与返奖率、金额与派奖档位、期限（兑奖期、活动起止）、活动参与方式、公益金比例、门店地址电话营业时间。

写法统一：【待核对：以中国福彩网 / 当地市中心发布口径为准】。宁可整句不写，也不给一个看起来合理的数字。
