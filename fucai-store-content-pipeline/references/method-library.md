# 方法库（一句话调用）

用户只发下列指令时，直接产出对应结果，不套六段模板；需要配图或成片时再补 C/D 段。核心内容仍受 `compliance-guardrails.md` 约束。

## 十二种调用

| # | 用户说什么 | 产出什么 |
|---|---|---|
| 1 | 「12 个选题」/「给我选题」 | 一个月 12 条选题表：序号、主题、栏目归属（门店日常/规则科普/公益理性/官方活动）、钩子一句、建议发布日。四类各 3 条，避开四类高风险 |
| 2 | 「改成三个平台」/「老内容三平台改写」 | 同一条内容的三版：抖音（口语、钩子前置、带话题）、视频号（稳一点、适合中年受众、少网络语）、朋友圈（≤80 字、无话题标签、结尾带门店信息） |
| 3 | 「5 个标题」/「标题 A/B」 | 5 个平台标题（各 ≤20 字）+ 对应封面 8 字；标注哪 2 条作为 A/B 测试，说明测试变量（提问式 vs 陈述式 / 数字 vs 无数字，注意数字须为官方口径） |
| 4 | 「评论区话术」/「应答库」 | 8 条合规答法，覆盖微信买、推荐号、中奖传闻、代刮代兑、活动真假、未成年人、内幕、赊账 |
| 5 | 「转述这段活动」 | 把官方活动原文转成：60 秒口播稿 + 朋友圈文案 + 海报文字块；规则、档位、日期原样保留，改不动的直接抄，抄不准的标【待核对】 |
| 6 | 「服务信息卡」 | 门店服务卡：营业时间、地址、新票到店、兑奖提醒、便民服务、不向未成年人售彩提示；排版为可直接打印的文字块 |
| 7 | 「公益口径」 | 3–5 条公益金与理性购彩表达，每条 40 字内，可直接做字幕/海报文字 |
| 8 | 「直播预告」 | 直播预告文案（时间+主题+看点）+ 30 分钟口播提纲；硬性写明不直播售彩、不荐号、不带线上交易，评论区应答同步给出 |
| 9 | 「复盘上周」/「周数据复盘」 | 按完播率、互动率、到店人数、留存人数四项做简表，给 3 条下周选题建议与 1 条改进动作（如钩子换成提问） |
| 10 | 「排一周」/「一周排期」 | 周二、周四、周日三条全套 A–E，含发布时间与话题；留 4 条备用选题 |
| 11 | 「只输出文案」/「只要口播」 | 只给【B】段正文与断句，不输出 C/D/E |
| 12 | 「语音输入」/「怎么用」 | 说明：按住话筒说「主题：XXX」即可，可补「门店：」「想发：」；识别错字直接再发一遍修正，无需重述 |

## 纠错指令（收到即改，不解释改法）

| 用户说 | 动作 |
|---|---|
| 「再口语一点」 | 去书面词、去长句，改成人说话的语气，句子 ≤12 字 |
| 「缩短到 80 字」 | 压到 80 字（±3），先砍修饰，保住钩子与结尾口径 |
| 「把钩子换成提问」 | 0–3 秒改成问句，仍 ≤12 字，不设悬念诱导点击 |
| 「删掉所有数字」 | 删净阿拉伯数字与金额；确需保留的规则数字改【待核对】 |
| 「只输出文案」 | 只回【B】 |
| 「换个分镜」 | 只替换【C】的 1 张分镜提示词，其余不动 |
| 「结尾只说到店咨询」 | 12–15 秒只留到店/营业时间，仍保留「理性购彩，量力而行」 |

改完后必须重跑 `scripts/check_copy.py`，字数与断句达标才交付。
